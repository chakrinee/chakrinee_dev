01 — About

Security depth meets agentic engineering

I'm a cybersecurity graduate student at the University of Maryland who spends most of my time somewhere most security people don't: inside the agent loop itself. I build the multi-agent systems — orchestration, retrieval, tool use — and then I build the guardrails that keep them from misbehaving in production.

That combination started at Kodryx AI, where I mapped LLM attack surfaces and shipped detection rules against real alert volume, and it sharpened at Tesslate, where I shipped full-stack features for a production AI platform and built the runtime tool-misuse guardrails that keep its coding agent in check, aligned to the OWASP Agentic Security (ASI02) risk class.

I'm not interested in security bolted on after the fact. I want to be in the room while the agent architecture is still being decided — because that's the only place these controls actually hold.
